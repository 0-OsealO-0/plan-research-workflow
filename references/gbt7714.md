# GB/T 7714-2015 参考文献规则（中文课程论文与学位论文）

学校模板和期刊投稿要求优先于本文件；这里只给通用规则，用来在没有模板时把格式做对。

本机没有支持 GB/T 7714 的格式化工具：`academic-paper` 的 `formatter_agent` 只支持
APA 7.0、Chicago、MLA 9、IEEE、Vancouver。中文文献请按本文件手工著录，再用
`academic-paper` 的 citation-check 做一致性与存在性核验。

## 顺序编码制

正文按引用先后编号，用方括号上标或行内 `[1]`；文末按编号顺序排列，编号与正文一一对应。

## 著录格式

期刊论文：

```text
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

专著：

```text
[2] 作者. 书名[M]. 版本. 出版地: 出版者, 出版年: 起止页码.
```

学位论文：

```text
[3] 作者. 题名[D]. 城市: 学校, 年.
```

会议论文：

```text
[4] 作者. 题名[C]//编者. 论文集名. 出版地: 出版者, 年: 起止页码.
```

标准：

```text
[5] 标准编号 标准名称[S]. 出版地: 出版者, 年.
```

专利：

```text
[6] 专利申请者. 专利题名: 专利号[P]. 公告日期.
```

电子资源：

```text
[7] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

报纸：

```text
[8] 作者. 题名[N]. 报纸名, 出版日期(版次).
```

## 文献类型标识

| 标识 | 类型 |
|---|---|
| M | 专著 |
| J | 期刊 |
| C | 论文集、会议录 |
| D | 学位论文 |
| R | 报告 |
| S | 标准 |
| P | 专利 |
| N | 报纸 |
| EB/OL | 电子公告、联机网络资源 |
| DB/OL | 数据库、联机网络 |

## 作者规则

- 3 人以内全部列出；超过 3 人列前 3 人，后加 `, 等`（英文文献用 `, et al.`）。
- 西文作者姓前名后，名可缩写且不加缩写点；团体作者写全称。
- 责任者不明时用 `佚名` 或 `Anonymous`，不要留空。

## 常见错误

- 期刊缺卷、期或页码；三项必须齐全。
- 网页缺引用日期，或只有 URL 没有发布日期。
- 沿用 APA 的 `&`、年份前置、句末句号位置。
- 中文文献用英文标点，或中英文标点混用。
- 正文编号与文末顺序不一致；同一文献重复编号。
- 把 DOI 直接当 URL 粘贴；按模板决定保留 DOI 还是 URL。

## 交稿前检查

1. 每条都有文献类型标识。
2. 作者数量符合 3 人规则。
3. 期刊条目有年、卷(期)、页码。
4. 网页条目有发布或更新日期，以及引用日期。
5. 正文编号与文末条目逐一对应。
6. 中文条目用中文标点，英文条目用英文标点。
